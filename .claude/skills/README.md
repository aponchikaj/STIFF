# Skills Library

50 Agent Skills grouped by domain. Each entry lists the trigger phrases that
should fire it. Validate the library any time with `node scripts/validate-skills.js`
from the repo root.

Note: the original build brief referenced 15 pre-existing skills
(marketing-plan, launch, ads, ...); they are not installed in this environment,
so this index covers the 50 skills that exist here.
